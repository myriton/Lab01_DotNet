# Выводы
1. Благодаря компиляции в IL-код и среде CLR, одна и та же программа на C# может работать на Windows, Linux и macOS
2. В C# нужно явно указывать тип переменной. Это помогает находить ошибки ещё до запуска программы
3. Console.ReadLine() всегда возвращает строку, поэтому для математических операций её нужно преобразовывать в число

# Ответы на вопросы
1. Console.Write() выводит текст в консоль без перехода на новую строку. Курсор остается в конце выведенного текста. Console.WriteLine() выводит текст и добавляет символ перехода на новую строку в конце, поэтому следующий вывод начнется с новой строки
2. Произойдет ошибка компиляции. Тип int предназначен только для хранения целых чисел
3. Потому что 10 и 3 целыe числа. При делении целых чисел выполняется целочисленное деление, при котором дробная часть отбрасывается. Чтобы получить дробный результат, нужно, чтобы хотя бы одно число было с плавающей точкой
4. Это ключевое слово, которое позволяет компилятору автоматически определить тип переменной. В C# тип переменной, объявленной через var, определяется один раз и навсегда на этапе компиляции. В Python переменная может в любой момент изменить свой тип (сначала хранить число, а потом строку)
